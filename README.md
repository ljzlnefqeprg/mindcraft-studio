## 🤖 Overview

MindCraft Studio combines a large-language model writing assistant with an AI image generator in a single canvas, turning ideas into illustrated documents.

Whether you're a newcomer or a veteran, MindCraft Studio provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Dual Canvas** | Write text and generate matching images side-by-side |
| **AI Brainstorm** | Generate mind maps and idea trees from a single seed concept |
| **Style Boards** | Collect visual references and have AI generate in that style |
| **Export PDF** | Export the finished illustrated document as a polished PDF |
